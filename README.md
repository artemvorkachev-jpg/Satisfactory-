# Satisfactory — мобильный одиночный проект

Проект разрабатывается как самостоятельная игра, вдохновлённая промышленным строительством и исследованием в Satisfactory. Оригинальные игровые файлы, модели, текстуры и звуки не копируются: ресурсы создаются процедурно и должны проходить собственную проверку.

## 3D-ресурсы

- Исходники Blender: `assets/models/**/*_four_variants.blend`
- Экспорт для просмотра и игры: четыре GLB-варианта A–D на семейство.
- Листы предпросмотра: `assets/models/previews/`
- Процедурные PBR-карты: `assets/textures/procedural/`
- Интерактивный просмотрщик: `viewer/`

Откройте [3D Model Viewer](./viewer/) после публикации репозитория через GitHub Pages. Просмотрщик поддерживает поиск, категории, четыре варианта модели, вращение и масштабирование.

## Звуки

Оригинальные процедурные WAV-файлы и карта событий находятся в `assets/audio/generated/`. Формат: WAV PCM, 48 kHz, 16-bit, stereo. Файлы не являются извлечёнными или скопированными звуками Satisfactory.

## Сборка и проверка

GitHub Actions workflow **Build Blender asset blockouts** выполняет:
1. генерацию исходных Blender-моделей и GLB;
2. создание оригинальных PBR-текстур и UV-развёрток;
3. генерацию WAV-звуков;
4. рендер листов предпросмотра;
5. проверку GLB, встроенных изображений, WAV и полноты файловых наборов;
6. создание каталога для 3D-просмотрщика;
7. сохранение результатов в `main`.

## Важное ограничение по полноте

Количество файлов само по себе не означает, что воссозданы все объекты оригинальной игры. Реестр объектов должен быть сверён с конкретной версией Satisfactory и внутриигровым Codex/build menu. Сгенерированные геометрии являются самостоятельными стилизованными блок-аутами/дизайн-вариантами, а не точными копиями оригинальных моделей. Неуточнённые размеры, анимации, коллизии и производственные соединения нельзя считать утверждёнными без отдельной проверки.

## Структура

- `assets/models/` — модели и предпросмотр
- `assets/textures/procedural/` — карты albedo, roughness и height
- `assets/audio/generated/` — оригинальные звуки и manifest
- `tools/blender/` — генерация, UV/PBR, предпросмотр и валидация
- `tools/audio/` — генератор оригинального аудио и спецификация
- `viewer/` — интерактивный веб-просмотрщик
